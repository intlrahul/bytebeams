# Sparkee Design System

Sparkee is the mandatory UI source of truth for ByteBeams. It provides the
subtle-blue, Material 3 light theme, semantic colours, typography, spacing,
radii, and reusable operational UI primitives.

Feature UI must consume Sparkee rather than declaring local visual tokens or
typography. Status is always communicated by text and icon in addition to
colour. Light theme is required; dark theme is out of scope for this demo.

The temporary Sparkee catalogue is an internal verification surface. It is not
a replacement for product routes and will be replaced by Fleet Home in the
next milestone.
